# 🍲 Food Recipes Web App

A responsive and modern Food Recipes web application built using HTML, CSS, Bootstrap, and JavaScript. This project uses a public API to fetch and display recipes dynamically based on user search input.

---
## 🚀 Previw



## 🚀 Features

- 🔍 Search recipes in real-time
- 🍽️ Fetch live data from TheMealDB API
- 📱 Fully responsive design
- 🎨 Clean and modern UI
- ⚡ Dynamic recipe cards rendering
- ❌ No results handling

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)
- TheMealDB API
